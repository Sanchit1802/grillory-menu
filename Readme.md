# Grillory Menu

A modern frontend restaurant menu website built to display food items in a clean,
responsive, and user-friendly interface.

## ✨ Features
- Responsive UI
- Category-based menu
- Special item highlighting
- Clean layout
- Mobile-friendly design

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- React
- Vite

## ⚙️ Installation
1. Clone the repository  
git clone https://github.com/Sanchit1802/grillory-menu.git 

2. Go to project folder  
cd grillory-menu 

3. Install dependencies
npm install  

4. Run project  
npm run dev
